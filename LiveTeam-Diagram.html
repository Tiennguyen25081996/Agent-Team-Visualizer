Code:
```tsx
export const inject = ['slots']

export function apply(ctx: Context) {
  ctx.slots.inject('conversation.view', () => ctx.slots.register(
    {
      id: 'agent-team-visualizer',
      label: 'Live Team',
      order: 20,
    } ,
    LiveTeamView,
  ))
}
```

🖼️ src/dsh-live-entry.tsx

1. Đọc Dữ Liệu từ Host:
```typescript
props.useSessions(state => ...)
  state.projectionsBySession[sessionId].values.agentTeam
state.get(member.id)?.running
```
2. Map Status:
✅ failed → Done
⏳ provisioning → Idle
▶️ running → Working
3. Render 3D Scene:
└── LiveDesk (grid layout workstations)
├── Members orbit when idle
└── Working agents stay seated
└── OfficeCameraController (zoom/pan/orbit)
Callees:
└── LiveDesk → OfficeCameraController
├── requestCamera
└── zoomCamera
